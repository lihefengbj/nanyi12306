# nanyi12306

12306 火车票自动购票桌面工具（个人自用）。

基于 Python + PySide6，同时支持 Windows 和 macOS。通过 12306 官方接口实现扫码登录、余票监控与自动下单，下单成功后在 12306 官方 App 内手动完成支付。自动候补链路尚未验证，当前禁用；请通过官方 App 提交候补。

> **合规说明**：本工具仅供个人使用，采用低频轮询（≥1.5s + 随机抖动），不绕过验证码、不调用任何第三方接口、不囤票不牟利。12306 禁止高频第三方请求，滥用可能导致账号被限制，请合理设置轮询间隔。

## 功能特性

- 官方 App 扫码登录，Cookie 本地持久化，免重复登录
- 车站名自动补全（内置车站代码表）
- 多任务并行监控：车次白名单、席别优先级、时间窗过滤
- 余票命中自动下单，排队状态实时展示
- 无票继续监控；候补请通过 12306 官方 App 提交
- 出票提醒：系统弹窗 + 声音 + 微信推送（Server酱/Bark 可选）
- Windows / macOS 单安装包分发

## 界面预览

三个主页面：**登录页**（二维码扫码）→ **任务页**（配置抢票条件）→ **监控页**（实时余票、排队状态、日志）。详见 [docs/界面设计.md](docs/界面设计.md)。

## 快速开始

```bash
# 需要 Python 3.11+
pip install -r requirements.txt
python main.py
```

打包分发（在对应平台上执行）：

```bash
python build/build.py        # 自动识别 Windows / macOS
```

产出：Windows 为 `dist/nanyi12306.exe`，macOS 为 `dist/nanyi12306.app`。

## 使用流程

1. 启动应用，用 12306 官方 App 扫描二维码登录
2. 新建抢票任务：选择出发地/目的地/日期，查询后勾选车次，设置席别优先级和乘车人
3. 点击「开始抢票」，切到监控页观察状态
4. 下单成功后应用弹窗并响铃，**10 分钟内**到 12306 App「未完成订单」中支付

## 测试

```bash
python -m unittest discover -s tests -q   # 99 项离线测试，不访问真实 12306
```

测试覆盖登录流程、Cookie 持久化、余票查询解析、时间窗过滤、下单链路
（含 initDc 解析、字段组包、订单保护）与日志诊断，全部基于伪造 transport。

出发时间窗同时作用于查询结果、监控展示和下单筛选，包含起止时刻（如
18:00–18:59）；修改时间后会立即过滤已查询的结果，无需再次请求。时间窗按
所选日期计算，结束时间不能早于开始时间。无票车次仍保留展示供监控选择。

余票查询入口由本站查询页的 `CLeftTicketUrl` 配置及查询响应的 `c_url` 指定，
不再固定猜测 `/leftTicket/query`。同账号多任务共享查询间隔及失败冷却，下单
整段流程串行执行。下单使用所选乘车日期，不使用列车始发日；查询和下单
失败分别退避。确认提交响应丢失、排队超时或需要验证码时停止自动重提，
显示「需人工处理」，请先在 12306 App 核对未完成订单。

## 项目结构

```
nanyi12306/
├── main.py                # 应用入口
├── ui/                    # PySide6 界面层
│   ├── main_window.py     # 主窗口 + 页面导航
│   ├── login_page.py      # 二维码登录页
│   ├── task_page.py       # 抢票任务配置页
│   ├── monitor_page.py    # 实时监控页
│   └── widgets.py         # 车站补全、任务卡片等组件
├── core/                  # 业务核心（后台线程）
│   ├── auth.py            # 扫码登录 + Cookie 管理
│   ├── stations.py        # 车站代码表
│   ├── query.py           # 余票查询与解析
│   ├── order.py           # 下单 / 候补链路
│   ├── worker.py          # QThread 抢票工作线程
│   └── notify.py          # 跨平台通知
├── data/                  # 运行时数据（Cookie、配置、缓存）
├── assets/                # 图标、提示音
├── build/                 # PyInstaller 构建配置
├── docs/                  # 项目文档
└── requirements.txt
```
