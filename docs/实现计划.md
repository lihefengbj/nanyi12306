### 登录联调修复记录（重要）

1. `create-qr64` 必须 POST 且带 `appid=otn`，GET 返回 `result_code:9`
2. 扫码状态码实际含义：0=未识别，1=已识别待授权，2=成功，3=失效，5=系统异常
3. `checkqr` 成功时服务器 Set-Cookie `uamtk`（**Path=/passport**），/otn 路径看不到它——手动种 Cookie 造成同名重复会导致 `auth/uamtk` 302
4. 正确换票链：`auth/uamtk`（uamtk→newapptk）→ `uamauthclient`（tk=newapptk）→ `userLogin`，与官网 `/otn/passport` 中转页 JS 一致
5. `finish_login` 每步校验 result_code，最后 checkUser 兜底，杜绝"假登录"
