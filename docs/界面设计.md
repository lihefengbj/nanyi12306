# 界面与交互设计

PySide6 实现，单窗口 + 左侧导航切换三个页面。整体走简洁工具风格，信息密度优先。

## 1. 主窗口

```
┌──────────────────────────────────────────────────┐
│ nanyi12306                            [_][□][×]  │
├──────────┬───────────────────────────────────────┤
│ ▸ 登录    │                                       │
│ ▸ 抢票任务 │            当前页面内容                │
│ ▸ 监控    │                                       │
│ ▸ 设置    │                                       │
├──────────┴───────────────────────────────────────┤
│ ● 已登录: 张三    轮询中(2任务)    2026-10-02 23:00 │
└──────────────────────────────────────────────────┘
```

- 左侧导航 + 底部状态栏（登录状态、活跃任务数）
- 窗口最小化时收进系统托盘，任务不中断

## 2. 登录页

```
┌────────────────────────────────┐
│      请使用 12306 App 扫码      │
│                                │
│        ┌──────────────┐        │
│        │              │        │
│        │   二维码      │        │
│        │              │        │
│        └──────────────┘        │
│                                │
│      状态：等待扫码…            │
└────────────────────────────────┘
```

- 状态机：等待扫码 → 已扫码，请在手机上确认 → 登录成功（自动跳转任务页）
- 二维码过期自动刷新；Cookie 有效时跳过此页

## 4. 监控页

```
┌──────────────────────────────────────────────────┐
│ ┌─ 任务1 北京南→上海虹桥 10-08 ────────────[停止]─┐ │
│ │ 状态: ● 监控中   已轮询 142 次  间隔 ~2.1s      │ │
│ │ G103 二等:有 一等:有  |  G107 二等:3 一等:有    │ │
│ └───────────────────────────────────────────────┘ │
│ ┌─ 任务2 上海虹桥→北京南 10-15 ───────────[停止]─┐ │
│ │ 状态: ◉ 排队中  前方 12 人  预计 45s            │ │
│ └───────────────────────────────────────────────┘ │
├──────────────────────────────────────────────────┤
│ 日志:                                             │
│ 23:00:01 [任务1] 查询完成，无符合条件车次           │
│ 23:00:03 [任务2] 命中 G107 二等座，提交订单…       │
│ 23:00:05 [任务2] 进入排队队列，前方 12 人           │
│ 23:00:47 [任务2] ✅ 下单成功！订单 E123456789      │
└──────────────────────────────────────────────────┘
```

- 每个任务一张卡片：状态用颜色区分（监控中=绿、排队中=黄、成功=蓝、失败=红）
- 日志面板可过滤任务、可复制；错误行红色高亮
- 下单成功：任务卡片显示订单号 + 10 分钟支付倒计时，同时触发通知

## 5. 设置页

- 轮询间隔（下限 1.5s，默认 2s）+ 抖动范围
- 通知开关：桌面弹窗、声音、Server酱 SendKey、Bark URL
- 定时候轮：勾选后按 12306 起售时间自动开始任务
- Cookie 管理：查看登录账号、退出登录

## 6. 交互细节

- 所有网络操作异步执行，UI 不阻塞；按钮在请求期间置灰
- 任何接口异常以非阻塞 toast 提示，同时写入日志
- macOS 与 Windows 外观统一使用 Qt Fusion 风格微调，避免两端观感差异过大
- 高 DPI：启用 `AA_EnableHighDpiScaling`（兼容 Retina）
